AntiHunter wipe code

Turns your erase key and a node's token into the short code that wipes the node over the mesh. Runs in this browser only. Nothing is sent anywhere. Short codes need Beta firmware that includes erase-key support. Stable needs the full 64-character answer.

  1. Send @NODE ERASE_REQUEST from your Meshtastic app.
  2. Paste the AH_... token from the reply below.
  3. Send the command this page shows. The token works once and expires after 5 minutes.
